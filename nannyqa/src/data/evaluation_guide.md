# 评估维度说明

## 核心维度

| 维度 | 英文名 | 权重 | 说明 |
|------|--------|------|------|
| 工作经验 | experience_level | 0.15 | 从事保姆/家政工作时长和经历 |
| 健康状况 | health | 0.10 | 身体健康，无重大疾病 |
| 烹饪技能 | cooking_skill | 0.08 | 家常菜、辅食制作能力 |
| 育儿经验 | parenting_experience | 0.12 | 带孩子经验，年龄覆盖范围 |
| 应急处理 | emergency_response | 0.10 | 孩子生病、受伤时的处理能力 |
| 情绪照护 | emotional_care | 0.08 | 理解并回应孩子情绪需求 |
| 卫生习惯 | hygiene | 0.08 | 清洁消毒、家务组织能力 |
| 安全意识 | safety | 0.08 | 家庭安全隐患识别和处理 |
| 沟通能力 | communication | 0.07 | 与雇主、家人的沟通技巧 |
| 职业道德 | ethics | 0.06 | 诚实、保密、责任心 |
| 职业素养 | professionalism | 0.05 | 工作态度、稳定性、薪资期望 |
| 老人照护 | elder_care | 0.03 | 照顾老人的经验和耐心 |

## 综合评分标准

| 分数范围 | 评级 | 建议 |
|----------|------|------|
| 90-100 | ⭐⭐⭐⭐⭐ 优秀 | 强烈推荐，各方面表现突出 |
| 80-89 | ⭐⭐⭐⭐ 良好 | 推荐，具备良好素质和经验 |
| 70-79 | ⭐⭐⭐ 合格 | 可以考虑，某些方面需提升 |
| 60-69 | ⭐⭐ 需改进 | 不建议录用，除非有特别优势 |
| <60 | ⭐ 不推荐 | 不适合从事家政工作 |

## 各维度详细评估标准

### 工作经验 (experience_level)
- 5分：10年以上经验，带过大孩子和婴儿，有多家庭服务经历
- 4分：5-10年经验，熟悉日常育儿和家务
- 3分：2-5年经验，有一定基础
- 2分：1-2年经验，需要学习
- 1分：刚入行或无经验

### 健康状况 (health)
- 5分：健康良好，无慢性病，体检合格
- 4分：基本健康，有小毛病但不影响工作
- 3分：有一些慢性病史但控制良好
- 2分：有较严重健康问题，需要定期治疗
- 1分：健康狀況不佳，不适合从事体力劳动

### 烹饪技能 (cooking_skill)
- 5分：精通家常菜，会做辅食，能根据孩子口味调整
- 4分：会做多种家常菜，了解辅食制作
- 3分：能做基本家常饭，辅食需要学习
- 2分：只会简单炒菜，缺乏系统性
- 1分：烹饪经验有限

### 育儿经验 (parenting_experience)
- 5分：有自己的孩子，经验丰富，熟悉各年龄段育儿特点
- 4分：有带孩子经验，了解基本育儿知识
- 3分：带过别人孩子，有一定经验
- 2分：经验较少，需要指导
- 1分：无育儿经验

### 应急处理 (emergency_response)
- 5分：掌握基本急救知识，知道如何呼叫救护车，能快速判断情况
- 4分：了解处理方法，知道何时需要就医
- 3分：有一定应急意识，但知识不够系统
- 2分：缺乏应急知识，需要培训
- 1分：完全不知道如何处理紧急情况

### 情绪照护 (emotional_care)
- 5分：能准确识别孩子情绪，及时安抚，注重心理建设
- 4分：能回应孩子情绪需求，方法得当
- 3分：会安慰孩子，但深度不够
- 2分：处理方式较粗糙，可能忽视情感需求
- 1分：缺乏同理心

### 卫生习惯 (hygiene)
- 5分：讲究卫生，熟悉消毒流程，家务有条理
- 4分：注重清洁，知道基本卫生要求
- 3分：有卫生意识，但细节不够到位
- 2分：卫生习惯一般
- 1分：不讲卫生

### 安全意识 (safety)
- 5分：熟悉家庭安全隐患，掌握急救技能，有应急预案
- 4分：有安全意识，知道基本防范措施
- 3分：有一定安全意识，但不够全面
- 2分：安全意识较弱
- 1分：缺乏安全意识

### 沟通能力 (communication)
- 5分：善于沟通，能理解雇主需求，及时反馈问题
- 4分：沟通顺畅，能表达清楚自己的想法
- 3分：基本沟通没问题，但主动性不够
- 2分：沟通有些困难
- 1分：不善于表达

### 职业道德 (ethics)
- 5分：诚实守信，注重隐私，有责任心
- 4分：品行端正，能遵守基本职业规范
- 3分：基本诚实，但有些细节需要注意
- 2分：职业道德意识一般
- 1分：存在诚信问题

### 职业素养 (professionalism)
- 5分：工作态度认真，稳定性高，目标明确
- 4分：工作态度较好，有一定的职业规划
- 3分：基本符合要求，但缺乏主动性
- 2分：工作态度一般
- 1分：缺乏职业素养

### 老人照护 (elder_care)
- 5分：有丰富的老人照护经验，耐心细致
- 4分：有一定老人照护经验
- 3分：照顾过老人，但经验有限
- 2分：几乎没有老人照护经验
- 1分：完全不懂老人照护
